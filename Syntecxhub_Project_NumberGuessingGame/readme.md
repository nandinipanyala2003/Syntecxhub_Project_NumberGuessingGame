## 🎯 Project Overview
Interactive console-based Number Guessing Game with **advanced features**:
- 3 Difficulty levels (Easy/Medium/Hard) with max attempts limit
- Hot/Cold temperature hints (distance-based)
- Real-time **timer** tracking
- **Leaderboard** with file persistence (scores.txt)
- Personal best score tracking
- Input validation & error handling
- Professional CLI interface with emojis

## ✨ Key Features Implemented
- `random` module - Secret number generation [Loops]
- `while` loops - Game flow & replay system
- `if-elif-else` - Hints, validation, win/lose logic
- `try-except` - Input error handling
- `time` module - Performance timer
- File I/O - Leaderboard save/load
- Functions - Modular code structure

## 🚀 How to Run
1. Download/Clone project folder
2. Open terminal in `Syntecxhub_Project_NumberGuessingGame/`
3. Run: `python game.py`
4. Choose level → Start guessing!
5. Beat your best score & check leaderboard
